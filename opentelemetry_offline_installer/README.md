# 📦 OpenTelemetry Offline Installer

This folder contains a prepackaged `.tar.gz` archive for installing OpenTelemetry components in offline environments.

---

## 🔧 Installation Instructions

Run the following commands from your terminal:

```bash
# Extract the archive
tar -xzf opentelemetry_offline_installer.tar.gz

# Navigate into the extracted directory
cd opentelemetry_offline_installer

# Make the install script executable
chmod +x install_all.sh

# Run the installer
./install_all.sh
